# AUVANTEO Digital Studio

Website institucional da AUVANTEO (TanStack Start + React + Tailwind).

```sh
bun install
bun run dev     # desenvolvimento
bun run build   # produção
```

Contactos (WhatsApp e Instagram) em `src/lib/contact.ts`.
O número de WhatsApp pode ser substituído pela variável `VITE_WHATSAPP_NUMBER`.
